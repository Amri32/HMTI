# Dokumentasi Konten Website HMTI Margonda

## 1. Latar belakang

Website HMTI Margonda akan dipublikasikan melalui Instagram HMTI Margonda sebagai bukti bahwa program kerja pembuatan website telah berjalan. Dokumen ini menggabungkan dan menjelaskan empat konsep postingan yang sebelumnya disimpan dalam empat file CSV.

Dokumen ini ditujukan agar manusia maupun AI agent berbasis CLI dapat memahami isi brief tanpa harus membuka Excel, Google Sheets, atau file CSV satu per satu.

## 2. Tujuan konten

- Mengumumkan bahwa website HMTI Margonda sudah selesai atau sudah dapat diakses.
- Menunjukkan hasil nyata program kerja Divisi Kominfo HMTI.
- Memperkenalkan halaman dan fitur utama website.
- Mendokumentasikan proses pembuatan website, termasuk penggunaan AI jika konsep tersebut dipilih.
- Mengarahkan audiens Instagram untuk mengunjungi website melalui tautan atau QR Code.

## 3. Audiens utama

- Mahasiswa dan anggota HMTI Margonda.
- Pengurus serta pembina organisasi.
- Calon anggota HMTI.
- Pengunjung Instagram HMTI Margonda.

## 4. Empat alternatif konsep postingan

## 6. Arah yang paling sesuai dengan kebutuhan

Berdasarkan konteks bahwa postingan ini akan digunakan sebagai bukti program kerja website telah berjalan, **Konsep A paling relevan sebagai konsep utama** karena menunjukkan hasil nyata dan bagian-bagian website. Konsep D dapat dipakai jika tim menginginkan versi lebih singkat.

Jika dokumentasi proses memang tersedia, satu atau dua unsur dari Konsep B dapat dimasukkan tanpa mengubah fokus utama. Konsep C sebaiknya dipilih hanya jika HMTI memang ingin menjadikan penggunaan AI sebagai pesan publik utama.

Rekomendasi susunan final yang seimbang:

1. Cover: “Website HMTI Margonda Telah Live!”
2. Halaman Home: profil dan sambutan.
3. Halaman Program Kerja: informasi dan transparansi kegiatan.
4. Halaman Galeri: dokumentasi kegiatan.
5. Halaman lain atau fitur unggulan yang benar-benar tersedia.
6. Dokumentasi proses atau foto tim Kominfo.
7. Tautan website, QR Code, dan ajakan mengunjungi website.

## 7. Data yang masih harus dilengkapi

Bagian berikut masih berupa placeholder dan tidak boleh ditebak oleh AI agent:

- `[link website]` atau `[link]`: alamat website resmi yang aktif.
- `[X] Hari`: durasi pengerjaan yang sebenarnya.
- `[nama-nama]`: nama anggota yang benar-benar terlibat.
- `[ChatGPT/Claude/Copilot/Cursor]`: hanya cantumkan tools yang benar-benar digunakan.
- Foto tim, screenshot proses, error, terminal, dan mockup: gunakan hanya jika dokumentasinya tersedia dan aman dipublikasikan.
- QR Code: harus dibuat dari URL final dan diuji sebelum posting.

## 8. Catatan akurasi dan keamanan publikasi

- Jangan menampilkan API key, token, password, cookie, file `.env`, alamat database, data anggota yang bersifat pribadi, atau informasi rahasia pada screenshot.
- Potong atau blur data sensitif pada tampilan terminal, chat AI, dashboard hosting, dan riwayat Git.
- Jangan mengklaim fitur yang belum tersedia di website.
- Pastikan nama divisi, nama anggota, link, dan status “telah live” sudah benar sebelum desain dipublikasikan.
- Gunakan screenshot dengan ukuran dan tampilan yang konsisten, idealnya dari versi website yang sama.
- Pastikan QR Code dapat dipindai dari layar ponsel sebelum desain diserahkan.

## 9. Instruksi untuk AI agent

Saat diminta membaca dokumen ini, lakukan hal berikut:

1. Pahami bahwa empat konsep di atas adalah alternatif arahan konten Instagram untuk dokumentasi website HMTI Margonda.
2. Jangan langsung mengubah source code, desain, atau file project hanya karena dokumen ini dibaca. Lakukan perubahan hanya jika pengguna memberi perintah lanjutan yang eksplisit.
3. Jangan mengarang data untuk placeholder. Tanyakan atau tandai data yang belum tersedia.
4. Jika diminta menyusun konsep final, prioritaskan bukti program kerja dan fitur yang benar-benar ada di website.
5. Jika memiliki akses ke repository website, audit halaman dan fitur aktual terlebih dahulu sebelum menulis klaim konten.
6. Bedakan antara teks yang akan tampil pada slide, arahan visual, caption Instagram, dan data faktual yang masih perlu dikonfirmasi.
7. Gunakan bahasa Indonesia yang natural, ringkas, dan sesuai akun organisasi mahasiswa; hindari kalimat berlebihan atau klaim yang tidak dapat dibuktikan.
